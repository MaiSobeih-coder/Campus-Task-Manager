# 📝 Campus Task Manager Pro

A modern, full-stack Task Management application designed for students to organize their academic life efficiently. This project features a stunning **Glassmorphism UI**, dynamic real-time statistics, and a robust Spring Boot REST API, fully containerized for easy deployment.

## 🚀 Tech Stack
- **Backend:** Java 25, Spring Boot 4.0, Spring Data JPA
- **Database:** H2 (In-Memory)
- **Frontend:** HTML, CSS (Bootstrap 5 + Custom Glassmorphism), Vanilla JavaScript
- **DevOps:** Docker (Multi-stage build), Docker Compose, GitHub Actions (CI)
